# events.tsv files as published in version 1.0.4

Version 1.0.5 merges the HFS markers that the authors' analysis file repeats from the acquisition file into one row
each (6 rows) and adds rows decoded from the TRIG channel. So that no published row is lost, both events.tsv files of
version 1.0.4 are kept here byte for byte, at the same relative path. They are not read by BIDS tools.
